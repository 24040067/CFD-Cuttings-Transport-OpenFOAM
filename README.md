# CFD-Cuttings-Transport-OpenFOAM

# Research plans

| Step                                  | Work required                                                                                                                                                               | Deliverable / completion criterion                                                                                                                                |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Fix the research scope**         | Define the research question, intended outputs, assumptions, and exclusions.                                                                                                | Agreed one-page problem specification.                                                                                                                            |
| **2. Audit experimental data**        | Inspect Zenodo and METU sources for geometry, rheology, particle properties, operating conditions, measurements, and uncertainty. Assess axial and rotational flow regimes. | At least one reproducible laminar benchmark identified; missing information documented. If none is suitable, revise scope before developing the multiphase model. |
| **3. Review the closest literature**  | Identify studies addressing the same configuration and outputs. Establish what our work will add.                                                                           | Focused comparison table and a defensible contribution statement.                                                                                                 |
| **4. Specify the mathematical model** | Select equations, coupling, particle transport description, closures, and boundary conditions appropriate to the benchmark.                                                 | Complete model specification, including validity limits and conservation statements.                                                                              |
| **5. Develop and verify the code**    | Follow the development stages below.                                                                                                                                        | Verified solver with reproducible cases and documented numerical errors.                                                                                          |
| **6. Validate against experiments**   | Compare predictions with measurements using a fixed model configuration. Separate any calibration cases from validation cases.                                              | Validation results, uncertainty discussion, and a clearly stated range of applicability.                                                                          |
| **7. Conduct a pilot study**          | Test a small flow-rate–rotation matrix within the validated regime.                                                                                                         | Evidence that the parameter range is informative, affordable, and physically appropriate.                                                                         |
| **8. Run the main study**             | Execute a controlled parameter campaign with automated diagnostics and consistent output definitions.                                                                       | Complete, traceable publication dataset.                                                                                                                          |
| **9. Interpret and write**            | Explain the mechanisms, quantify trade-offs, and discuss limitations.                                                                                                       | Manuscript with verified methods, validation evidence, and supported conclusions.                                                                                 |
| **10. Prepare submission**            | Review technical consistency, reproducibility, references, and journal requirements.                                                                                        | Submission-ready article and supporting code/data.                                                                                                                |
